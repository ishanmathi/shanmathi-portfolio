# Shanmathi I — Personal Portfolio

A responsive dark-themed portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Before publishing — important edits
- Replace `your.email@example.com` with your real email address.
- Replace the LinkedIn and GitHub placeholder URLs with your profile URLs.
- Replace each `https://github.com/` project link with the correct repository.
- Add working demo links where available.
- Verify certificate names, dates and achievement wording against your original records.
- Add your own project screenshots if you want the cards to show real application screens.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive dark theme and visual styling
- `script.js` — mobile navigation and current year

No frameworks or build tools required.
